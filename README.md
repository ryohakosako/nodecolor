# ノードカラーシミュレーター v4

ビルド・外部ライブラリ不要のHTML/CSS/JavaScriptアプリ。画像・OBJを端末内で処理します。Git構成設定・Push・公開は行っていません。

## 起動

nodecolorフォルダーで node server.cjs を実行し http://localhost:4173/nodecolor/ をChromeで開きます。停止はCtrl+C。index.htmlを直接開くこともできますが、継続使用には同じHTTPアドレスを推奨します。localhostと127.0.0.1は別の保存領域です。GitHub Pagesのサブパス向けに相対パスを使用しています。

## ノード

- ＋固有色: カラーピッカーとHEX（6桁/#付き6桁）で編集。元の色と照明後を同じノード内で比較。
- ＋照明: 主光源・環境光・反射光・ハイライト・背景を1ノードに集約。1つの照明一式出力端子から、固有色の照明一式入力へドラッグまたは順次クリックで接続。出力は複数へ、入力は1本で新規接続時に置換。線のクリックか入力横の×で解除。
- 主光源・反射光・ハイライトは方位0〜360°、上下角−90〜90°で全方位に設定。環境光は方向を持たない均一な光。方向が同じハイライトを使う場合は主光源と同じ角度を設定します。
- 背景の色は照明ノードから接続して共有。未接続は中立の固定背景。個別の背景編集欄はありません。背景は照明計算に含みません。
- ＋画像: 画像ノード内の「画像を読み込む」、またはノードへファイルをドロップ。PNG/JPEG/WebP/GIF/BMP、20MB/4000万画素まで。長辺1024pxへ縮小し、透明部分を白へ合成。大きなPNGはJPEGへ圧縮する場合があります。画像はサーバーに送信しません。
- 固有色の「スポイト」を押し、画像ノード・オブジェクト・グラデーションをクリックするとそのピクセル色を適用。Escで中止。

## 3Dオブジェクト

固有色ノードの「OBJを読み込む」から.objを選択。形状を読み込み、ノードの固有色を形状全体へ適用します。照明の接続・色・強さ・3D方向の変更を反映します。オブジェクト画面のドラッグで左右360°・上下90°に回転できます。球・立方体・平面への切り替えも可能です。OBJ読み込み後も組み込み形状へ切り替え、再び読み込んだOBJへ戻れます。

対応はテキストOBJのv・vn・f、負インデックス、法線参照。10MB、頂点3万、法線9万、三角形分割後5万面まで。多角形はファン分割するため、三角形または凸面を推奨。全体を中央へ移動し表示サイズへ正規化します。面積ゼロなど表示不能のデータは拒否します。

MTL・テクスチャ・元のマテリアル色・UV・骨格・アニメーション・FBX・glTFは未対応です。OBJの外部参照は読みません。全パーツを1つの固有色で着色し、両面表示します。モデルごとの材質分けは未実装です。

## グラデーションと色コード

グラデーションの任意位置をクリックすると、実際に表示されたピクセルのHEXをノード内へ保存。1ノード32色まで。保存色は自動保存・JSONに含みます。色番号をクリックすると選択とクリップボードコピーを行い、×で削除します。

## キャンバスとPNG保存

上部ドラッグでノード移動、余白ドラッグで視点移動、ホイールか±で拡大縮小、全体表示で全配置を表示。

「ノードを画像保存」は画面外も含めた全ノード・接続線・画像・オブジェクト・保存色をPNGへ書き出します。ツールバーは含みません。DOMの文字・入力値・Canvasを専用描画器で描き直すため、ブラウザ表示の完全なピクセルコピーではありません。既定1倍（保存前のダイアログで0.25〜4倍を変更し、出力サイズを確認可能）、長辺8192px/2400万画素に収まる倍率へ調整。ノードが極端に離れている場合（6万単位超）は近くへ配置して保存してください。

## 保存と互換性

IndexedDBへ画像データ・OBJテキスト・各設定・保存色・回転・接続・視点を自動保存。使えない場合はlocalStorageへフォールバックし、保存できない場合は通知します。JSONの書き出し/読み込みはversion 4（24MBまで）。画像・OBJを追加する際のシーン全体は22MBまで。ノード追加は100個（旧データの設定を保持する移行照明を含む読込は200個）・接続500本まで。

旧v1/v2/v3も読み込みます。別々の光・背景ノードを照明ノードにまとめ、固有色と接続先の種類を保持。同種の光が複数ある場合は複数の照明グループへ分けて残します。ノードの大型化と統合に合わせ位置を再配置します。旧localStorageは残します。旧個別背景編集は廃止。照明計算の変更により旧版との見た目の完全一致は保証しません。

## 色と3Dの計算

sRGBをリニアRGBへ変換。固有色Bに対し、均一環境光、主光源のLambert拡散（係数1.3）、反射光の方向付き拡散（係数0.7）、視線とハイライト方向の中間ベクトルによる40乗の鏡面項（係数0.65）を合成し、sRGBへ戻して表示範囲へ制限します。環境項は0.08＋0.55×環境光強度×環境光色。主光源・環境光が未接続なら中立の既定光を使用します。背景は計算外です。

3Dは正投影のソフトウェアラスタライザー。法線による頂点色を補間し、Zバッファで前後関係を処理します。グラデーションは主光源方向に対する法線を反対側から正対まで動かした33点の色を補間します。物理的な光輸送や投影影の厳密な再現ではなく、配色検討用です。大きいOBJはCPU負荷が上がります。

## 検証

node --test tests/model.test.cjs でモデル・移行・OBJ・方向・Zバッファ・描画範囲を確認。tests/browser.html は生成した画像/OBJでデコード・描画・保存復元・PNG生成をブラウザ内で検証します。検証用IndexedDBは本体と隔離します。確認結果はVERIFICATION.md、ブラウザ結果はtests/browser-results.txt。

OSファイルダイアログからの実ユーザーファイル選択、ダウンロード先の実ファイル確認、複雑な実モデル、他ブラウザ/タッチは今回未確認。Undo/Redo、材質ごとの着色は未実装です。

## 方向操作とミュート（v4）
主光源・反射光・ハイライトは球のマーカーをドラッグして方向を指定。手前／奥を選んで前後の半球を切り替えます。左上・右上・正面・真上・下・逆光のプリセット、折りたたんだ数値入力も使用可能。各照明項目のチェックを外すと値を保持して寄与ゼロ、背景オフは固定色 #30343F。出力1つから複数の固有色へ接続できます。
旧形式の種類別接続が混在している場合は、その組み合わせを保持する移行照明を追加します。旧設定値を持つ元の照明も残します。方向・オンオフ・PNG倍率は自動保存とJSONに含まれます。
